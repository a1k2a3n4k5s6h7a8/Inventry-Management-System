Inventory Management System

A beginner-friendly C++ Inventory Management System developed using Object-Oriented Programming (OOP) and file handling.

Features
Add new products
Display all products
Search products by ID
Update product details
Delete products
Save and load inventory data using a text file
Technologies Used
C++
OOP
STL Vector
File Handling
How to Run

Compile the project:

g++ main.cpp Product.cpp Inventory.cpp -o inventory

Run:

./inventory
Project Purpose

This project was developed to practice C++ programming, OOP concepts, data management, and file handling through a practical inventory management application.
